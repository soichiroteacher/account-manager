# アカウント管理アプリ

生徒の Google アカウント、学習サービスのアカウント、タブレット端末、学年だより・ホームページなどへの名前・顔写真の掲載の可否を、1つの名簿でまとめて管理するアプリです。
生徒一人ひとりに配る「アカウントシート」(B5・1人1枚)を印刷することもできます(PDFにも保存できます)。

### アカウントシートをPDFにするには

1. 「アカウントシート ▼」→「全員分のシートを印刷」(1人分なら一覧の「シート印刷」)を押します。
2. 印刷画面の「送信先」(「プリンター」)で **「PDFに保存」** を選び、「保存」を押します。
3. プリンターで印刷するときは、用紙サイズ「B5」、倍率「既定」または「100%」を選んでください。

## 使う前に(担当の先生が最初に1回だけ)

1. このフォルダ(`index.html`・`app.js`・`crypto.js`・`style.css`・`lib` フォルダ)を、校務共有サーバーの決められたフォルダにコピーします。
2. **Chrome または Edge** で `index.html` を開きます。
3. 「データファイルを新しく作る(最初の1回だけ)」を押し、`アカウント名簿.json` を **`index.html` と同じフォルダ** に保存します。

## 使い方

1. 共有サーバーの `index.html` を、Chrome または Edge で開きます。
   - 初回は「データファイルを開く」で `アカウント名簿.json` を選びます。2回目からは自動で開きます。
2. 開いた直後は「閲覧のみ」です。名簿を見る・検索する・書き出すことができます。
3. 名簿を直すときは、画面右上の「編集する」を押します。
   - 初めて編集するときは、名前を聞かれます(ほかの先生の画面に「○○さんが編集中」と出ます)。
   - 変更は自動で保存されます。
4. 終わったら「編集を終える」を押します。押し忘れても、しばらく操作がなければ自動で編集を終えます。

画面上部のボタンとメニュー(「▼」の付いたボタンを押すと、中の項目が出ます):

| ボタン・メニュー | 中の項目とできること |
|---|---|
| 生徒を追加 | 1人ずつ登録する(編集中のみ) |
| アカウントシート ▼ | 「全員分のシートを印刷」で配布用のシートを印刷する(印刷画面で「PDFに保存」を選べばPDFにもなる)。「シートの設定」で学校名や文言を変える(編集中のみ) |
| Excel・CSV ▼ | 「Excel書き出し」「Excel読み込み」「Excelテンプレート」で、Excel でまとめて登録・更新する。「Google管理コンソール用CSV」で、Google のアカウントを一括登録するファイルを作る |
| まとめて処理 ▼ | 「パスワード一括生成」で、パスワードが空欄の生徒にまとめて作る。「年度更新」で卒業・進級の処理をする(実行前に必ずバックアップ)。編集中のみ表示 |
| バックアップ ▼ | 「データを書き出す(バックアップ)」「データを読み込む(復元)」 |
| 設定 | 編集者の名前、自動で編集を終えるまでの時間、名前・写真の掲載で確認する項目など |
| 使い方 | このアプリの使い方(年度更新やExcelの取り込みの手順、困ったときの対処など)を画面で見る |

詳しい使い方は、アプリの右上の「使い方」にもあります。

### 名前・写真の掲載(学年だより・ホームページなど)

- 生徒の編集画面の「名前・写真の掲載」で、項目ごとに「可」「不可」「未確認」を記録します。条件は「メモ」に書きます。
- 初めの項目は「学年だより・学級通信などに名前/顔写真」「ホームページに名前/顔写真」の4つです。「設定」で追加・名前の変更・削除ができます。
- 学年だよりなどを作るときは、一覧の上の切り替えで「掲載不可: ○○」を選ぶと、載せてはいけない生徒だけが表示されます。
- 同意書をまとめて入力するときは、Excel の「掲載:〜」の列に「可」「不可」(○・×でも可)を入れて取り込めます。

## データの保存場所

- 名簿は、共有サーバーの **`アカウント名簿.json`**(`index.html` と同じフォルダ)に保存されます。
  - 2026年9月26日以前に作ったものは `アカウント名簿.dat` という名前です。そのまま使えます。
- 名簿は校内でだけ扱います。**インターネットやクラウド(Googleドライブ等)には置かないでください。**
- このパソコンのブラウザには、編集者の名前と、前回開いたファイルの場所だけを覚えています。

## バックアップと復元

- **バックアップ**:「バックアップ ▼」→「データを書き出す(バックアップ)」を押すと、`アカウント管理_バックアップ_日付.json` が保存されます。年度更新やExcelでの一括読み込みの前には、必ずバックアップを取ってください。
- **復元**:「編集する」を押してから「バックアップ ▼」→「データを読み込む(復元)」を押し、バックアップのファイルを選びます。確認のメッセージが出たあと、名簿がバックアップの内容に置き換わります。

## 困ったとき

| こんなとき | どうする |
|---|---|
| 「このブラウザではデータファイルを開けません」と出る | Chrome か Edge で開き直してください。 |
| パスコードを聞かれる | 以前の形式のファイルです。担当の先生にパスコードを確認して1回だけ入力し、「編集する」を押してください。次からは聞かれなくなります。 |
| 「○○さんが編集中」と出て編集できない | その先生の編集が終わるのを待ってください。10分以上操作がなければ、表示は自動で消えます。 |
| 「保存できませんでした」と出る | 共有サーバーにつながっているか確認し、「編集を終える」を押してもう一度保存してください。 |
| 間違えて消した・壊れた | 「データを読み込む(復元)」で、直前のバックアップに戻してください。 |

## 後任の先生・開発者へ

- 仕組み・注意点・次にやることは [HANDOFF.md](HANDOFF.md) にまとめています。変更の記録は [CHANGELOG.md](CHANGELOG.md) です。
- 学校ごとの設定(アカウントシートの文言・パスワードの作り方・自動で編集を終えるまでの時間など)は、アプリの「設定」と「アカウントシート ▼」→「シートの設定」から変えられます。
- 練習や動作確認には、`sample` フォルダの **`見本データ_アカウント名簿.json`**(架空の生徒14人)を使えます。デスクトップなど別の場所にコピーしてから、「データファイルを開く」で開いてください(編集すると、開いたファイルが書き換わるため)。
- 同梱しているライブラリ(`lib` フォルダ):SheetJS 0.18.5(Excel読み書き)。インターネットなしで動くように同梱しています。
