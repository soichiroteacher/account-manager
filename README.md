# アカウント管理アプリ

生徒の Google アカウント、学習サービスのアカウント、タブレット端末を1つの名簿でまとめて管理するアプリです。
生徒一人ひとりに配る「アカウントシート」(B5・1人1枚)を PDF で作ることもできます。

## 使う前に(担当の先生が最初に1回だけ)

1. このフォルダ(`index.html`・`app.js`・`crypto.js`・`style.css`・`lib` フォルダ)を、校務共有サーバーの決められたフォルダにコピーします。
2. **Chrome または Edge** で `index.html` を開きます。
3. 「データファイルを新しく作る(最初の1回だけ)」を押し、`アカウント名簿.json` を **`index.html` と同じフォルダ** に保存します。

## 使い方

1. 共有サーバーの `index.html` を、Chrome または Edge で開きます。
   - 初回は「データファイルを開く」で `アカウント名簿.json` を選びます。2回目からは自動で開きます。
2. 開いた直後は「閲覧のみ」です。名簿を見る・検索する・書き出すことができます。
3. 名簿を直すときは、画面右上の「編集する」を押します。
   - 初めて編集するときは、名前を聞かれます(ほかの先生の画面に「○○さんが編集中」と出ます)。
   - 変更は自動で保存されます。
4. 終わったら「編集を終える」を押します。押し忘れても、しばらく操作がなければ自動で編集を終えます。

主なボタン:

| ボタン | できること |
|---|---|
| 生徒を追加 | 1人ずつ登録する |
| Excel読み込み / Excelテンプレート | Excel でまとめて登録・更新する |
| パスワード一括生成 | パスワードが空欄の生徒に、まとめてパスワードを作る |
| 全員分シートPDF出力 | 配布用のアカウントシートを作る |
| Google管理コンソール用CSV | Google のアカウントを一括登録するためのファイルを作る |
| 年度更新 | 卒業・進級の処理をする(実行前に必ずバックアップ) |

## データの保存場所

- 名簿は、共有サーバーの **`アカウント名簿.json`**(`index.html` と同じフォルダ)に保存されます。
  - 2026年9月26日以前に作ったものは `アカウント名簿.dat` という名前です。そのまま使えます。
- 名簿は校内でだけ扱います。**インターネットやクラウド(Googleドライブ等)には置かないでください。**
- このパソコンのブラウザには、編集者の名前と、前回開いたファイルの場所だけを覚えています。

## バックアップと復元

- **バックアップ**:「データを書き出す(バックアップ)」を押すと、`アカウント管理_バックアップ_日付.json` が保存されます。年度更新やExcelでの一括読み込みの前には、必ずバックアップを取ってください。
- **復元**:「編集する」を押してから「データを読み込む(復元)」を押し、バックアップのファイルを選びます。確認のメッセージが出たあと、名簿がバックアップの内容に置き換わります。

## 困ったとき

| こんなとき | どうする |
|---|---|
| 「このブラウザではデータファイルを開けません」と出る | Chrome か Edge で開き直してください。 |
| パスコードを聞かれる | 以前の形式のファイルです。担当の先生にパスコードを確認して1回だけ入力し、「編集する」を押してください。次からは聞かれなくなります。 |
| 「○○さんが編集中」と出て編集できない | その先生の編集が終わるのを待ってください。10分以上操作がなければ、表示は自動で消えます。 |
| 「保存できませんでした」と出る | 共有サーバーにつながっているか確認し、「編集を終える」を押してもう一度保存してください。 |
| 間違えて消した・壊れた | 「データを読み込む(復元)」で、直前のバックアップに戻してください。 |

## 後任の先生・開発者へ

- 仕組み・注意点・次にやることは [HANDOFF.md](HANDOFF.md) にまとめています。変更の記録は [CHANGELOG.md](CHANGELOG.md) です。
- 学校ごとの設定(アカウントシートの文言・パスワードの作り方・自動で編集を終えるまでの時間など)は、アプリの「設定」「アカウントシート設定」から変えられます。
- 同梱しているライブラリ(`lib` フォルダ):jsPDF 2.5.1(PDF作成)、html2canvas 1.4.1(画面を画像にする)、SheetJS 0.18.5(Excel読み書き)。インターネットなしで動くように同梱しています。
