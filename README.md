# 名簿・アカウント管理

(2026-11-21 に「アカウント管理」から名前を変えました。フォルダ名 `account-manager` は同じです。)

生徒の Google アカウント、学習サービスのアカウント、タブレット端末、学年だより・ホームページなどへの名前・顔写真の掲載の可否を、1つの名簿でまとめて管理するアプリです。
生徒一人ひとりに配る「アカウントシート」(B5・1人1枚)を印刷することもできます(PDFにも保存できます)。

職員(先生方)の名簿とアカウントも管理でき、年度ごとの役割分担(校務分掌)を **ツリー(組織図)** と **表** で見て印刷できます。回覧用の職員名簿も印刷できます。画面の上の「生徒」「職員」「役割分担」で切り替えます。

### アカウントシートをPDFにするには

1. 「アカウントシート ▼」→「全員分のシートを印刷」(1人分なら一覧の「シート印刷」)を押します。
2. 印刷画面の「送信先」(「プリンター」)で **「PDFに保存」** を選び、「保存」を押します。
3. プリンターで印刷するときは、用紙サイズ「B5」、倍率「既定」または「100%」を選んでください。

## 使う前に(担当の先生が最初に1回だけ)

1. このフォルダ(`index.html`・`app.js`・`crypto.js`・`sample-data.js`・`staff.js`・`guide.js`・`table-scroll.js`・`roster.js`・`style.css`・`lib` フォルダ)を、校務共有サーバーの決められたフォルダにコピーします。
2. **Chrome または Edge** で `index.html` を開きます。
3. 「データのフォルダを選ぶ」を押し、**`index.html` と同じフォルダ**(データを置くフォルダ)を選びます。フォルダにまだデータファイルがなければ「データファイルを作る」が出るので、「作る」を押します。`名簿・アカウント管理_2026年度.json`(年度は今の年度)ができます。
   - 今までの `アカウント名簿.json` を使っていた場合は、下の「今までのファイルからの移し替え」を見てください。

## はじめての方へ(見本で試す)

最初の画面の **「見本で試す」** を押すと、架空の生徒14人・職員15人の名簿と、2年分の役割分担で、すべての機能を練習できます。

- 見本で試している間は、画面の上に紫色で「見本で試しています」と出ます。
- 生徒の追加・編集、シートの印刷、Excel、年度更新なども試せますが、**データファイル(本物の名簿)は一切変わりません**。
- 終わるときは「見本を終える」を押します。見本で変えた内容は消え、次に試すときは元の見本に戻ります。
- 最初の画面の **「画面ガイドを見る」** を押すと、見本を開いて、画面の部品(ボタンや一覧)を1つずつ枠で囲んで説明します。「次へ」「戻る」で進み、「案内を閉じる」でやめられます。アプリの右上の「使い方」の一番上にある「画面ガイドを始める」からも、いつでも見られます。

## 使い方

1. 共有サーバーの `index.html` を、Chrome または Edge で開きます。
   - 初回は「データのフォルダを選ぶ」で、共有サーバーのデータのフォルダを選びます(パソコン・ブラウザごとに1回)。2回目からは、起動するだけで今の年度のファイルが開きます。
   - 「データのフォルダ「…」を開く」というボタンが出たときは、押して「許可する」を選んでください(ブラウザを開き直したときなどに出ます)。
2. 開いた直後は「閲覧のみ」です。名簿を見る・検索する・書き出すことができます。
3. 名簿を直すときは、画面右上の「編集する」を押します。
   - 名前を聞かれるので、自分の名前を入れて「OK」を押します(前回の名前が最初から入っています。空のままでは始められません)。ほかの先生の画面には「○○先生が編集中(15:20〜)」と出ます。
   - 変更は自動で保存されます。
4. 終わったら「編集を終える」を押します。押し忘れても、しばらく操作がなければ自動で編集を終えます。

画面上部のボタンとメニュー(「▼」の付いたボタンを押すと、中の項目が出ます):(「生徒を追加」「アカウントシート ▼」「Excel・CSV ▼」「まとめて処理 ▼」は「生徒」の画面だけに出ます)

| ボタン・メニュー | 中の項目とできること |
|---|---|
| 生徒を追加 | 1人ずつ登録する(編集中のみ) |
| アカウントシート ▼ | 「全員分のシートを印刷」で配布用のシートを印刷する(印刷画面で「PDFに保存」を選べばPDFにもなる)。「シートの設定」で学校名や文言を変える(編集中のみ) |
| Excel・CSV ▼ | 「Excel書き出し」「Excel読み込み」「Excelテンプレート」で、Excel でまとめて登録・更新する(読み込みは CSV ファイルも可)。「生徒名簿(印刷・Excel)」で、クラス名簿(チェック欄つき・男女別も可)・2クラス横並び・全クラス一覧・一覧表を印刷・罫線つきの Excel にする(パスワードは載らない)。「Google管理コンソール用CSV」で、Google のアカウントを一括登録するファイルを作る |

## 職員の名簿とアカウント(「職員」の画面)

- 上の「職員」を押すと、先生方の名簿が出ます。データは生徒と同じデータファイル(`名簿・アカウント管理_YYYY年度.json`)に保存されます(見られる人も同じです)。
- 「編集する」を押してから「職員を追加」で、職員番号・氏名・職名・Google などのアカウント・端末番号・備考を登録します。
- 「Excel書き出し」で一覧を Excel にし、直して「Excel読み込み」で取り込めます(職員番号、なければ氏名で同じ人を探して更新し、いない人は追加します)。
- ほかの名簿(Excel・CSV)もそのまま読み込めます。「名前」「職種」「フリガナ」「メールアドレス」のような見出し、姓と名が別の列(「姓」「名」「セイ」「メイ」)、1行目が題名の表も読みます。読み込む前に、どの列を読むか・読まないかを表示します。空の欄は、登録済みの内容を消しません。
- 「アカウントシートを印刷」で職員用のシート(B5・1人1枚)を印刷します。文言は「シートの文言」(編集中)で変えます。学校名は生徒のシートと同じです。
- 「回覧用の名簿(印刷・Excel)」で、在職中の先生の氏名・職名・担当と確認の欄が付いた表(A4 縦)を印刷します。「Excelで書き出す」を押すと、同じ表(ふりがなつき)を Excel のファイル(`題名_日付.xlsx`)にできます。パスワードなどのアカウントの情報は入りません。
- 異動した先生は、削除せずに「状況」を「転出・退職」にしてください。過去の年度の役割分担に名前が残ります。

## 役割分担(「役割分担」の画面)

- 年度ごとの校務分掌を、**ツリー**(指示系統の図)・**表(部署ごと)**・**表(職員ごと)** の3つの見せ方で表示します。
- はじめて使うときは「編集する」→「新しい年度を作る」→「+ 一番上に部署を追加」(例: 校長)から始めます。
- 部署・係の枠(表では行)を押すと、名前・上の部署・担当者(役割つき)・並び順を直せます。「この下に部署・係を追加」で下の部署や係を足します。
- 新しい年度は、前の年度を写して作れます(「転出・退職」にした先生は自動で外れます)。前の年度はそのまま残るので、年度を選べば過去の担当者が分かります。
- 「印刷」で、今見ている形のまま印刷します(ツリーは A3 横、表は A4 縦。入りきらないツリーは自動で縮めます)。印刷画面で「PDFに保存」も選べます。
- **Excel から作る**:「Excel読み込み」(編集中)で、Excel・CSV の分掌表から1年度分をまとめて作れます。表は「部署・係/上の部署/氏名/役割」の4列で、1行に担当者1人です(読み込みの画面の「記入例を書き出す」で見本がもらえます)。「部署」と「係」が別の列の表や、部署のセルを結合した表も読めます。読み込む年度がすでにあるときは、その年度が読み込んだ内容に置きかわります(読み込む前にバックアップを取ってください)。
- 「Excel書き出し」で、今の年度を同じ形の Excel にできます。書き出して直し、読み込み直すこともできます。

### 編集の記録

- 画面右上の「編集の記録」を押すと、だれが・いつ編集したかが新しい順に出ます(最大200件)。
- 記録されるのは名前と時刻だけです。何を変えたかは記録しません。内容を前に戻したいときは、「バックアップ」フォルダのファイルから復元してください。
- 記録は名簿のデータファイルの中に一緒に保存されます。
- 「見本で試す」では架空の記録が出ます。見本で編集しても記録は増えません。

### タブレット端末の故障・修理・交換の記録

- 生徒の編集画面の「タブレット端末」で「+ 記録を追加」を押し、日付・種類(故障/修理/交換/その他)・内容を入力します。
- 端末を交換したときは、種類を「交換」にすると「以前の端末番号」に今の番号が入ります。そのあと「端末番号」を新しい番号に直してください。
- 検索欄に以前の端末番号を入れると、その端末を前に使っていた生徒も見つかります。
- 生徒ごとに「ふりがな」を入れられます(ひらがな。姓と名の間にスペース)。検索欄でも、ふりがなで探せます。Excel では「ふりがな」の列で書き出し・読み込みができます。ふりがなは、定期テストアプリが名簿を読み込むときにも使います。
- 生徒ごとに「性別」(男・女)を入れられます(空でもかまいません)。名簿の「男女別」の並びと「性別」の列に使います。Excel の「性別」の列でまとめて入れられます(「男子」「女子」「M」「F」も読みます)。

### 生徒名簿(印刷・Excel)

- 「Excel・CSV ▼」→「生徒名簿(印刷・Excel)」で、学校でよく使う形の名簿を印刷したり、罫線つきの Excel に書き出したりできます。パスワードは載りません。
  - **クラス名簿**: 1クラス1枚(A4 縦)。出席番号・氏名(ふりがな・性別も選べる)と、チェック欄の列(数を選べる。見出しは 1, 2, 3 … か空欄)。見出しの行は高くしてあり、手書きで項目を書けます。下に空の行を足せます(転入生などを書き足すため)。
  - **2クラス横並び**: 2クラスずつ A4 横に並べたチェック欄つきの名簿。
  - **全クラス一覧**: 全クラスの氏名を A4 横1枚に並べます(6クラスごとに1枚)。
  - **一覧表**: 学籍番号・Google ID・端末番号なども選んで載せる表。
- 「男女別」を選ぶと、男子 → 女子の順に並び、境目の線が太くなります。
- クラス名の横に担任の名前が入ります(「役割分担」の今年度の担当、例:「第1学年」の「1組担任」から)。
- 一覧に表示中の生徒が対象です。学年やクラスだけにしたいときは、検索欄に「1年」「1年2組」などと入れてから開きます。
- Excel は1枚の紙に収まる印刷の設定にしてあるので、そのまま印刷できます。
- そのほか引き継いでおきたいことは「備考」に書きます。
- 2026年9月29日までの「修理中」の記録や端末のメモは、自動で「記録」と「備考」に移ります。

### 名前・写真の掲載(学年だより・ホームページなど)

- 生徒の編集画面の「名前・写真の掲載」で、項目ごとに「可」「不可」「未確認」を記録します。条件は「メモ」に書きます。
- 初めの項目は「学年だより・学級通信などに名前/顔写真」「ホームページに名前/顔写真」の4つです。「設定」で追加・名前の変更・削除ができます。
- 学年だよりなどを作るときは、一覧の上の切り替えで「掲載不可: ○○」を選ぶと、載せてはいけない生徒だけが表示されます。
- 同意書をまとめて入力するときは、Excel の「掲載:〜」の列に「可」「不可」(○・×でも可)を入れて取り込めます。

## データの保存場所

- 名簿は、共有サーバーのデータのフォルダ(`index.html` と同じフォルダ)に、**年度ごとのファイル**で保存されます。
  - 名前は **`名簿・アカウント管理_YYYY年度.json`**(例: `名簿・アカウント管理_2026年度.json`。年度は4月始まり)。
  - アプリは、名前の年度が一番新しいファイルを開きます。
- 自動のバックアップは、同じフォルダの中の **`バックアップ`** フォルダに入ります(下の「バックアップと復元」)。
- 名簿は校内でだけ扱います。**インターネットやクラウド(Googleドライブ等)には置かないでください。**
- このパソコンのブラウザには、編集者の名前と、データのフォルダの場所だけを覚えています。
- 定期テスト運営(exam-manager)は、このファイルから生徒の名簿を読みます。

### 新しい年度になったら

1. 4月になると、画面の上に「2027年度のファイルを作る」のような案内が出ます(自動では作りません)。
2. 押すと、生徒・職員・役割分担・設定を引き継いだ `名簿・アカウント管理_2027年度.json` ができて開きます。前の年度のファイルは、そのまま残ります(編集の記録は新しく始まります)。
3. 続けて「年度更新」(最上学年を卒業・ほかの学年を1つ上げる)をするか聞かれます。クラス替えは、そのあと Excel で取り込みます。
4. 前の年度のファイルは、「設定」→「ファイルを選んで見る」で見るだけで開けます。

### 今までのファイルからの移し替え(2026-11-21 より前から使っている学校)

1. 今までどおり `index.html` を開き、「データのフォルダを選ぶ」で、`アカウント名簿.json`(または `アカウント名簿.dat`)のあるフォルダを選びます。
2. 決まった名前のファイルがまだないので、今までのファイルが **見るだけ** で開き、「`名簿・アカウント管理_2026年度.json` の名前で保存し直す」ボタンが出ます。押すと新しい名前のファイルができ、次からはそれが開きます。
3. 元の `アカウント名簿.json` は消えずに残ります。定期テスト運営が新しいファイルを読めることを確かめてから、整理してください。

## バックアップと復元

- **自動のバックアップ**:「編集する」を押したとき、その日のバックアップがまだなければ、データのフォルダの中の `バックアップ` フォルダに1つ取ります(編集を始める前の状態)。名前は `名簿・アカウント管理_2026年度_バックアップ_2026-11-21_0830.json` のようになります。何人が編集しても1日1つです。新しい年度のファイルを作る前と、復元する前にも取ります。
- **エクスプローラーで日付の名前にコピーしておく必要は、もうありません**(自動で取られるため)。
- **アプリはバックアップを消しません。** 件数は「設定」の「データのフォルダとバックアップ」に出ます。増えすぎたら、古いものをエクスプローラーで消してください(例: 1か月より前のものは月に1つだけ残す)。
- **手で書き出す**:「バックアップ ▼」→「データを書き出す(バックアップ)」で、好きな場所に `名簿・アカウント管理_YYYY年度_バックアップ_日付.json` を保存することもできます。
- **復元**:「バックアップ ▼」→「データを読み込む(復元)」(または「設定」→「ファイルを選んで見る」)で、`バックアップ` フォルダのファイルを選びます。選んだファイルは **見るだけ** で開き、画面の上に「見るだけで開いています」と出ます。中身を確かめて「この内容に戻す」を押すと、今の年度のファイルがその内容に置き換わります(置き換える前の状態もバックアップに取ります)。やめるときは「いつものファイルに戻る」を押します。
- 見るだけで開いたファイルは直せません。次に起動したときは、いつものファイルが開きます。

## 困ったとき

| こんなとき | どうする |
|---|---|
| 「このブラウザではデータファイルを開けません」と出る | Chrome か Edge で開き直してください。 |
| パスコードを聞かれる | 以前の形式のファイルです。担当の先生にパスコードを確認して1回だけ入力し、「編集する」を押してください。次からは聞かれなくなります。 |
| 「○○先生が編集中」と出て編集できない | その先生の編集が終わるのを待ってください。15分以上保存がなければ、表示は自動で消えます。 |
| 「保存できませんでした」と出る | 共有サーバーにつながっているか確認し、「編集を終える」を押してもう一度保存してください。 |
| 間違えて消した・壊れた | 「データを読み込む(復元)」で `バックアップ` フォルダのファイルを選び、「この内容に戻す」を押してください。 |
| 「データのフォルダを開けませんでした」と出る | 共有サーバーにつながっているか確かめて、「データのフォルダを選ぶ」で選び直してください。 |
| 「見るだけで開いています」と出て編集できない | バックアップや前の年度のファイルを開いています。「いつものファイルに戻る」を押してください。 |
